# 🚀 AZ-204 Code Samples – Developing Solutions for Microsoft Azure

This repository contains a curated collection of **hands-on code samples and mini-projects** designed to support preparation for the **AZ-204: Developing Solutions for Microsoft Azure** certification.

It serves as a practical reference for implementing core Azure services, covering real-world scenarios across compute, storage, security, and integration.

---

## 📌 Overview

The goal of this repository is to:

- Provide **practical implementations** of Azure services
- Reinforce concepts required for the **AZ-204 certification**
- Demonstrate **real-world cloud development patterns**
- Serve as a **quick revision guide before exams/interviews**

Each module focuses on a specific Azure service or concept, making it easy to explore independently.

---

## 🧱 Repository Structure

The repository is organized into multiple folders, each representing a key Azure topic.

Typical areas covered include:

- ⚙️ **Azure App Services** – Hosting and deploying web applications  
- 🔐 **Azure Key Vault** – Secure storage of secrets and keys  
- ⚡ **Azure Functions** – Serverless compute solutions  
- 📦 **Azure Storage** – Blob, Queue, and Table storage operations  
- 🛰️ **Event-driven Architecture** – Event Hubs / Service Bus  
- 🧠 **Application Insights** – Monitoring and telemetry  
- 🔑 **Authentication & Authorization** – MSAL / Azure AD  
- 🗄️ **Cosmos DB** – NoSQL database operations  
- 🌐 **API Management** – API gateway and policies  

Each folder typically contains:
- Source code
- Configuration files
- Setup instructions (if applicable)
